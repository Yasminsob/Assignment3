# Assignment3

Nothing for Sale is designed to feel like an online shopping website.
It holds items i will never necessarily use, but refuse to get rid of for multiple different reasons.
The website includes a filter system with three different categories, images of the items and a short description when an item is clicked.
The project was inspired by two main ideas: Nihilism and Hoarding.
I'm fascinated by the importance humans hold for nonessential objects. An object that means nothing to one individual can make another appreciate life. An object that simply takes up space can hold hope for being useful in the future.
